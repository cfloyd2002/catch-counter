How the counting works

Each frame is filtered for the ball colour. Every throw is a free-fall parabola with the same gravity, so each detected ball position votes for the apex times and heights it could belong to; peaks with support on both sides of the apex, moving steadily sideways, count as throws. Gravity in pixels is measured from your own clean arcs, which also turns apex heights into centimetres.

A pause longer than the run break ends a run. A low-frequency thud in the audio within 1.6 s of the last throw marks a drop; otherwise the run counts as a clean stop. Catches are throws, minus the dropped ball when it was seen falling.

The survival curve is a Kaplan–Meier estimate with clean stops treated as censored. The fitted line assumes the same drop chance p on every catch, estimated as drops ÷ (drops + catches).
